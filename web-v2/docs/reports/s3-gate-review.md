## 9. 仍然存在的差距（不阻塞放行，但必须记账）

### 差距 1：标签、难度、主题树（A-3）

- 现状：`QuestionSchema` 没有 `tags` / `difficulty`；`topics` 是平铺列表，没有父子结构。
- 为什么不"先做个筛选框"：没有数据支撑的筛选器等于给用户一个永远返回空结果的按钮，比没有更糟。
- 处理：登记为**契约缺口**，归 S1 补字段（`tags?: string[]`、`difficulty?: 1..5`、`parentTopicId?: string`），属容差外变更；S3 不硬塞。
- 影响面：只影响"筛选维度"，不影响记录结构与隔离。

### 差距 2：内置题库仍需改一行注册表（D-1）

- 现状：内置题库要在 `apps/web/src/data/banks.ts` 的数组里加一行；导入路径完全零代码。
- 为什么不改成"扫目录自动注册"：Vite 的 `import.meta.glob` 在 Node 测试环境不存在，会把可测性换掉。
- 处理：已登记在 `00` §9；S6 换成"配置化题库包清单"时可去掉这一行。

### 差距 3：真实浏览器的视觉走查未做

- 原因：本机浏览器控制器截图接口报「超过 10 MiB」，无法留证。
- 处理：给出 5 分钟人工清单（不改变放行结论，但要留痕）：

```
1) pnpm -F @quiz/web dev → 打开 http://localhost:5173
2) 桌面宽度：侧栏 5 项可点、题库页左右分栏不重叠、预览区不撑破
3) 缩到 375px：底部导航出现、侧栏隐藏、「我的」页不横向滚动
4) 刷题：选一个选项立刻高亮、提交后反馈色正确（对=绿 错=红）
5) 隐私窗口打开：出现黄色横幅，仍能答题
```
