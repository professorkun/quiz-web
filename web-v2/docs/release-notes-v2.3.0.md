# 题斋 v2.3.0 发布说明

发布日期：2026-11-20

本次发布包含执行方案 V2.1、V2.2 与 V2.3 的全部开发项（T-13 按 ADR-0007 延期）。

## 亮点

- **导入更宽容**：只挂课程链接的讲义可导入；讲义未知字段降级为警告；报错全中文并定位到字段。
- **提示词 v2**：讲义规范、三向关联、课程链接纪律、英语题型映射、输出前自检清单。
- **Word 导入（Beta）**：`.docx` 在 Worker 中解析，逐题确认、可全部接受高置信度、可导出草稿 JSON。
- **题库页**：查看答案不产生作答记录；`J/K` 连续翻题、`Esc` 收起、末题提示；按标签筛选。
- **题库管理**：导入题库可删除，确认框列四类条数、需输入题库名，级联清理八类键并自动切库。
- **品牌与动效**：题斋 / 墨纸朱；11 条动效分档；深色模式；`prefers-reduced-motion` 全关。
- **性能**：路由分包 + KaTeX / highlight.js / 云 SDK 懒加载，首屏 JS gzip 300.75 → **73.29 KB**；Lighthouse 移动端 **98**、CLS 0。

## 已知限制

- **Word**：只支持 `.docx`；旧版 `.doc`、扫描件、图片型文档不支持。表格卷建议选项单元格自带 `A.` 字母。低置信度题不会默认勾选。
- **公式/代码**：采用「先原文后渲染」两帧；首帧会短暂看到源码或纯文本代码。
- **PWA 改名**：从「通用刷题」改为「题斋」，已安装用户可能看到两个图标。`start_url` 未变，本地数据不会丢失；建议卸载旧图标后重新安装。
- **T-13**：材料复用与 cloze 未包含在本版（见 `ADR-0007-passages-cloze.md`）。

## 升级与验收

- 升级前建议「我的 → 导出学习记录」备份。
- 验收证据见 `docs/acceptance.md` 与 `docs/evidence/`。
- 构建：`cd web-v2 && pnpm verify`；部署静态服务需开启 gzip 与 hashed 资源长缓存。
