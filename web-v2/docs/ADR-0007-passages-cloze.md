# ADR-0007：是否启动「材料复用 + cloze」契约扩展（T-13）

- 状态：**暂缓（推 V2.4）**
- 日期：2026-11-20
- 决策人：产品 / 主程
- 关联：执行方案 T-13、默认值 Q8

## 背景

T-13 要给题库契约增加 `passages`（材料）与 `cloze`（完形/选填）渲染与判分，预计 10 人日，并会动到：

- `packages/core/src/schema.ts` 的题型枚举与判别联合；
- 扩展点扫描脚本（当前硬性要求 6 个题型成员）；
- 旧题库包导入回归（G3 必过项）。

默认值 Q8 已定：**不升 `SCHEMA_VERSION`，只加可选字段与新题型**。但「技术上可行」不等于「现在该做」——启动前必须先回答三个问题。

## 三个问题与结论

### 1. 完形/选填类题占比是否 > 30%？

**未证实（不计为「是」）。**

仓库里没有真实题库内容（产品刻意不预置题库），无法从代码侧统计。已知的演示/夹具题库只用于测试，不具代表性。

低成本取证方式（0.2 人日）：
1. 取 3 份真实课程文档，走提示词 v2 转成题库包；
2. 统计 `fill_blank` + 「同一材料下多题」的题数占比；
3. 若 ≥30%，说明材料复用是主路径，值得扩契约；否则一题一材质足够。

在拿到这份数据前，任何「按感觉很高」的判断都不作数。

### 2. 能否先用「一题一材质」顶替？

**是。**

当前六题型已经能表达完形/选填：把材料原文并进题干、每个空用 `fill_blank` 的 `{{b1}}` 表达即可。代价是：

- 同一篇材料在多题里重复存储（题库包体积上升）；
- 题与材料的视觉层级较弱，长材料阅读体验一般；
- 无法做「材料区折叠 / 共用材料计时」这类交互。

但这些都属于体验优化，**不影响做题与判分**。在占比数据出来前，一题一材质是成本最低的可用方案；提示词 v2 也已经明确「不要把整篇阅读硬拆成多题」。

### 3. 旧包回归谁负责？

**主程实现 + 产品验收，CI 门禁兜底。**

- 主程：契约只加可选字段；`validateBankPackage` 对旧包必须继续通过；新增 `legacy bank` 回归用例（无 `passages` / 无 `cloze`）。
- 产品：在 G3 出口逐条执行 A1–E3，旧包导入零报错为必过项。
- CI：`pnpm verify` + 旧包夹具回归；任一失败不得发版。

## 决策

按「两个『是』才启动」的规则：目前只有第 2 问为「是」，第 1 问未证实，因此**不启动 T-13，推 V2.4**。

V2.4 启动条件（全部满足）：

1. 真实文档抽样显示完形/选填占比 > 30%；
2. 一题一材质在真实题库上出现明确的体积或阅读问题（有数据）；
3. 旧包回归用例与责任人已排进迭代。

在此之前，材料类内容一律按「一题一材质」导入，不再扩契约。
