# 11 · 模板 — 新增阶段计划模板

> 用法：复制本文件为 `{序号}-S{n}-{阶段名}.md`，替换所有 `{}` 占位内容与 `【】` 提示文字后填写。
> 设计依据：PRINCE2 Stage Plan 的骨架（目标/产品/质量验收/依赖/风险/控制与容差）+ BDD 与 SMART 的验收写法。
> 硬规则：**验收标准在动手写第一行代码之前定稿**；每一条都要能被另一个人照文复现。

## 6. 验收标准

### A. 数据 / 内容

- [ ] {数量、唯一性、完整性、可追溯性}

### B. 功能

- [ ] {每条对应一个可见行为}

### C. 工程 / 质量

- [ ] {测试、CI、无未处理异常、无平台越界依赖}

### D. 关键场景（Given / When / Then）

1. **{场景名}**
   Given {具体前置状态}，When {一个动作}，Then {可观察、可判定的结果}。
2. **{不顺利场景：空 / 错 / 权限}**
   Given {…}，When {…}，Then {…}。
3. **{回退或异常场景}**
   Given {…}，When {…}，Then {…}。

> 三种场景必须齐：正常路径只写一条，空状态、错误状态、权限状态至少覆盖两个。
