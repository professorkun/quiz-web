## 1. 阶段目标

**目标陈述**：把模考做成"模板可配置"的通用能力，而不是旧版里写死的 `buildPaper()`；然后用**旧版六模块的逐条对照用例**证明新版没有退步——这是切换正式入口的前提。

**可衡量目标**

| 编号 | 指标 | 目标值 | 验证方式 |
| --- | --- | --- | --- |
| G5-1 | 模板可配置 | 题型数量、每题分值、筛选范围、时长四项均可配置 | 新增第二个模板不改代码 |
| G5-2 | 组卷正确 | 题量与总分严格等于模板定义 | 单测 + 对账 |
| G5-3 | 旧模板迁移 | JavaWeb 38 题 / 100 分模板可用且分值一致 | 对账表 |
| G5-4 | 空位计分 | 应用题按空位给分，与旧版规则一致 | 逐题对照 |
| G5-5 | 主观自评 | 自评不覆盖客观判分，成绩明细可回溯 | 用例 |
| G5-6 | 功能对等 | 旧版 6/6 冒烟在新版一一对应通过 | 对照用例表 |
| G5-7 | 多题库模考 | 两库各自模板互不干扰 | 交叉用例 |

---

## 2. 范围边界

**本阶段做**

- 试卷模板（`ExamTemplate`）：题型数量、每题分值、筛选范围（题库/主题/标签/难度）、时长
- 组卷、计时、交卷、自动判分
- 主观题自评与自评结果记录
- 应用题空位计分（保留 S1 迁移的空位结构）
- 迁移 JavaWeb 现有 38 题 / 100 分卷作为第一个模板
- 成绩页：总分、分题型得分、答题明细、错题回看入口
- 六模块对照用例（题库 / 刷题 / 模考 / 错题 / 知识 / 我的）

**本阶段不做**

- 不接云（成绩只存本地）
- 不做 PWA、不做无障碍（S6）
- 不做试卷分享、排行榜、多人在线（方案已排除）
- 不做自适应难度组卷（S7）
- 不为了"更强"而改旧卷面结构（对等优先于改进）

## 6. 验收标准

### A. 模考核心

- [ ] 模板四项配置（题型数量、每题分值、筛选范围、时长）全部生效
- [ ] 组卷结果题量、总分、题型分布严格等于模板；题量不足时明确报错而非少抽
- [ ] 计时准确，超时自动交卷并提示
- [ ] 交卷后成绩立即可得，客观题自动判分
- [ ] 应用/代码填空题按空位给分，逐空结果可见
- [ ] 主观题自评可选档，自评不影响客观题得分

### B. 数据

- [ ] 模考产生的 `Attempt` 带 `mode: "exam"`，与练习/复习数据分开统计
- [ ] 成绩记录含 `bankId`、`templateId`，可回溯到具体模板
- [ ] 同一模板重复考试产生多条独立成绩，互不覆盖
- [ ] 答题明细可定位到每道题与每个空位

### C. 功能对等

- [ ] 旧版 6/6 冒烟项在新版均有对应验证且通过
- [ ] 题库：搜索、知识点与题型筛选、题目预览可用
- [ ] 刷题：顺序/筛选刷题、上一题/下一题、续刷可用
- [ ] 模考：计时、组卷、判分、自评可用
- [ ] 错题：收集、重做、移出可用（新版按 S4 规则细化）
- [ ] 知识：讲义按题库主题关联，不再是写死常量
- [ ] 我的：记录、设置、导入导出可用

### D. 关键场景（Given / When / Then）

1. **卷面严格**
   Given JavaWeb 模板定义为 38 题 / 100 分，When 开始一次模考，Then 题目数为 38、总分为 100、题型数量与模板一致。
2. **题量不足**
   Given 某模板要求 40 题但筛选范围内只有 30 题，When 组卷，Then 拒绝开始并提示"可用题目 30 < 需要 40"，不生成残缺试卷。
3. **中断恢复**
   Given 模考进行到第 20 题、剩余 12 分钟，When 刷新页面，Then 回到第 20 题，已答内容与剩余时间合理恢复，作答顺序与选项顺序不变。
4. **空位计分**
   Given 一道应用/代码填空题含 5 个空，答对 3 空，When 交卷，Then 该题得分为 3/5 的比例分，明细显示哪两空错误。
5. **自评不覆盖客观分**
   Given 某主观题自评"部分正确"，When 查看成绩，Then 自评档位单独显示，客观题得分不受影响，成绩明细可回看原始作答。
6. **多库模板隔离**
   Given 演示题库配置了自己的 10 题 / 50 分模板，When 两个题库各考一次，Then 成绩分别归属各自 `bankId` 与 `templateId`，不互相计入。

### E. 不可接受的情形

- 组卷题量或总分与模板不符却"照常开始"
- 应用/代码填空题退化为整题对错
- 自评覆盖客观判分或无法追溯
- 为了"更通用"而改变旧卷面结构，导致成绩无法与旧版对照
- 六模块对等只做"看起来都有"，没有逐条对照证据

## 7. 阶段门禁检查单（Go / No-Go）

- [ ] G1 数据：模板校验、成绩归属、明细定位三项通过
- [ ] G2 功能：六模块对照全过，6/6 冒烟有对应证据
- [ ] G3 工程：组卷与判分单测全绿；无未处理异常
- [ ] G4 可回退：模板配置化，改回旧卷面只需改配置
- [ ] 功能对照表归档
- [ ] 打标签 `s5-feature-parity`

**这一关是整个项目的"证明题"：过不了，S6 就不该开始。**

## 8. 阶段特有风险与应对

| 风险 | 触发信号 | 应对 |
| --- | --- | --- |
| 借模考之名重做产品 | 开始讨论"更好的考试体验" | 对等优先；改进项写入 S7 |
| 卷面结构悄悄变了 | 分值加总不等于 100 | CI 加模板分值校验 |
| 空位结构在渲染中被摊平 | 明细无法定位空位 | 以 S1 空位 ID 为唯一来源 |
| 自评与判分互相污染 | 成绩忽高忽低 | 自评结果单字段存储，判分只读客观字段 |
| 对照表靠回忆填写 | 无逐条证据 | 每条对照项必须写"验证方式 + 结果" |

---

## 9. 回退方案

1. 模板回退：删掉新模板即可回到无模考状态，练习与复习不受影响。
2. 成绩数据：成绩记录只增不改，异常成绩可标记作废而非删除。
3. 版本回退：回到 `s4-review-loop`，学习闭环仍完整，仅缺模考。
4. 正式入口未切换，用户仍用旧版模考。
