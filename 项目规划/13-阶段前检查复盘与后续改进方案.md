## 0. 一句话结论

V1 的**工程骨架与学习闭环已经达成**，剩下的缺口集中在两处：**S6 上线收尾未完成**，以及**「知识」模块只有要点、没有能读的讲义与配套视频**。
因此后续改进的主线是：**先把 S6 收口，再把知识讲义从"要点列表"升级成"可精读、可看视频、可直接练本节"的学习内容**，其余增强项按证据排队，不提前动工。

### 3.2 视频播放技术选型

| 方案 | 特点 | 适用 | 本项目取舍 |
| --- | --- | --- | --- |
| 原生 `<video>` | 零依赖、离线可用、支持 mp4/webm；HLS 仅 Safari 系原生 | 直链文件 | **首选**，符合"运行时零第三方依赖"取向 |
| `video.js` | 完整播放器 UI + 插件生态，HLS/DASH 需配适配器 | 播放器本身是产品 | 暂不引入，体积与依赖不划算 |
| `Plyr` | 轻量 UI 层，不自带流媒体引擎 | 只想要好看的控件 | 暂不引入 |
| `hls.js` / Shaka | 解决 Chrome/Firefox 的 HLS/DASH | 直播与自适应流 | 暂不引入；m3u8 先给浏览器差异提示 |
| 站外 iframe（B 站 / YouTube） | 无需托管视频，但引入第三方请求与 Cookie | 公开教学视频 | **采用，但点击后才加载**，文字讲义不依赖它 |

**关键设计约束**：本项目 S2 起坚持"无云依赖、断网可练习"，PWA 也以此为目标。
因此视频必须**可选、可降级**——断网时讲义仍完整可读，视频区显示"需联网"而不是黑框或异常。

## 5. 改进方案（改进方向 / 优先级 / 预期效果 / 验收标准）

### I-1 · 知识讲义精读化 【P0】

**改进方向**
1. 把讲义从「一句话要点」升级为固定结构的一篇精读材料：
   `学习目标 → 一分钟速览 → 分节正文（概念/流程/代码/对比表）→ 配套视频 → 易错点 → 考点侧重 → 拓展阅读 → 自测清单 → 去练本节`。
2. 内容源改为 **Markdown 文件 + 生成脚本**（`lectures/NN-*.md` → `knowledge.json`），延续仓库「内容只改 Markdown、产物重新生成」的既有纪律；严禁手改生成物。
3. 正文统一走既有 `RichText` 渲染管线（Markdown + 代码高亮 + 公式 + DOMPurify），不新开一套 HTML 注入口。
4. 讲义按 `topicId` 与题目关联，底部提供「去练这一节」——把学与练接起来。

**预期效果（量化）**
- 7 篇讲义，每篇 ≥8 个小节、≥3000 字正文、含代码块与对比表、3～6 条学习目标、≥2 条易错点、≥1 个配套视频；总正文量 ≥50k 字（现状约 12KB 的要点，提升约 4～5 倍）。
- 学员不刷题也能靠讲义把知识点学明白；每篇末尾自测清单可直接检验。

**验收标准**

| 编号 | 标准 | 判定方式 |
| --- | --- | --- |
| A-1 | 7 篇讲义与 7 个 `topicId` 一一对应，无重复 `moduleId` | 机器断言，遍历 `knowledge.json` |
| A-2 | 每篇 ≥8 节、≥3000 字、含 ``` 代码块与 Markdown 表格、≥3 目标、≥2 易错点 | 内容包单测，逐篇 `it.each` 断言 |
| A-3 | 每篇有「这一节解决什么问题」「考试怎么考」「自测清单」三种小节 | 小节标题集合断言 |
| A-4 | 页面可按篇切换、目录/锚点跳转、当前篇常驻可见 | 手动场景：选第 5 篇 → 刷新 → 仍在同一篇 |
| A-5 | 断网时文字讲义完整可读、代码高亮正常、无控制台异常 | 断网手测（空/错场景） |
| A-6 | 「去练这一节」进入刷题页后知识点筛选生效，且题型/顺序/题量等其它设置不变 | 场景式 Given/When/Then |
| A-7 | 讲义不写任何学习记录，正确率/掌握度统计不因阅读而变化 | 阅读前后对比统计快照 |

### I-2 · 讲义视频能力（在线教学视频 + 直链） 【P0】

**改进方向**
1. 讲义只存**视频地址与元信息**（标题、说明、起播秒数），不存视频文件——题库包要能整体导入导出、要顾及小程序分包体积。
2. URL 解析抽成 `packages/core` 的纯函数，UI 只按解析结果分支渲染；支持四类：
   - **直链文件**（mp4/webm/ogv/m4v/mov）→ 原生 `<video>`，支持起播秒数、可拖进度；相对路径视为随包本地文件，不算联网。
   - **站点嵌入**（B 站 BV/av 号或完整链接、YouTube 11 位 id）→ 站外播放器 iframe，**点击后才加载**，另给"原站打开"。
   - **HLS**（m3u8）→ 提示 Safari 原生可播、其它浏览器建议改 mp4，不假装通用。
   - **普通网页 / 短链** → 只给跳转卡，不内嵌。
3. 安全：`javascript:` / `data:` / `vbscript:` 一律判非法并给出可读原因；解析失败渲染提示卡，不做黑框。
4. 内容侧可挂经过交叉核对的公开课程合集（如尚硅谷 JavaWeb / Spring5 / SpringMVC / MyBatis / JDBC 系列 BV 号），并留"填直链"能力供用户自行替换；**外链有效性需季度巡检**。

**预期效果**：讲义同时具备"看视频入门"与"读文字精读"两条路径；断网不影响文字；未点击前零第三方请求。

**验收标准**

| 编号 | 标准 | 判定方式 |
| --- | --- | --- |
| B-1 | B 站完整链接、裸 BV 号、mp4 直链、YouTube 链接四类解析结果正确 | core 单测覆盖正确/变体/错误/空值 |
| B-2 | 非法协议被拒且 `reason` 可读；解析不出时不渲染播放器 | 单测 + UI 断言 |
| B-3 | 站外视频未点击前不产生任何第三方网络请求 | 浏览器网络面板实测 |
| B-4 | 断网时点播放：显示"需联网"提示，讲义正文仍可滚动、可跳转 | 断网手测（错场景） |
| B-5 | 直链 mp4 可播放、可拖进度；`startSec` 生效 | 手动场景 |
| B-6 | 每条讲义至少 1 个可解析视频地址；全部条目通过解析器校验 | 内容包单测遍历 |
| B-7 | 视频区不进入 DOMPurify 管线之外的新注入口，`check:extension` 扫描通过 | 边界扫描脚本 |
