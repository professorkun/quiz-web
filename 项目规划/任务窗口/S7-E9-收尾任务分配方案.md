## 2. 全局硬约束（所有窗口必读）

1. **上传配置不可动**：`origin`（`https://github.com/professorkun/quiz-web.git`）、
   `credential.helper=manager`、`.gitattributes`（`* text=auto`）、`.github/workflows/**`、
   `pnpm-lock.yaml` 均不得修改；不执行 `push --force`、不改写 remote、不清理凭据。
2. **提交前先精确 `git add <路径>`**，禁止 `git add -A` / `git add .`：
   仓库内可能再出现临时 worktree（含 node_modules），卷入会触发 GitHub 大文件拒绝。
3. **CRLF 约定**：`core.autocrlf=true`。讲义 `*.md` 若从 git 检出为 CRLF，
   `build-knowledge.mjs` 的 front matter 解析只认 LF，需先 `sed -i 's/\r$//' *.md` 再生成。
4. **`*/dist/**` 禁止提交**：隔离 worktree 里跑测试需先 `pnpm --filter @quiz/core build`
   等补齐 dist；dist 只作本地验证产物。
5. **视频口径**：当前题库 `videos: []` 是**合法且预期**的形态。
   任何窗口不得因"没有视频"而重新塞回题库专属链接，也不得删除 Schema / 解析器 / VideoCard。
6. **P-2 = A 仍有效**：`router.ts` / `App.tsx` / `AppShell.tsx` 三方冻结。
7. **一个 commit 只属于一个窗口**，提交信息带窗口前缀。
