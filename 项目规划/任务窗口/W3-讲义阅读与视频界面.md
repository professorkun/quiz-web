## 1. 目标

做出"选一篇 → 精读 → 看视频 → 去练本节"的完整阅读体验，且**断网不崩、讲义自足**。
阅读位置只放组件状态，**不写入任何学习记录**（否则污染正确率/掌握度统计口径）。

## 4. 执行步骤

1. 写纯组件三件：`KnowledgePanel`（模块目录 + 单篇切换，按 `topic.order` 排序）、`LectureArticle`（元信息 → 目标 → 目录 → 分节正文 → 视频 → 易错点 → 拓展 → 练本节）、`VideoCard`。
2. 正文统一用既有 `RichText` 渲染（Markdown + 高亮 + 公式 + DOMPurify），**不新开 HTML 注入口**；目录锚点用 `sec-<index>`，切篇后回到顶部。
3. `VideoCard` 按 `parseMediaSource` 的 `kind` 分支：
   - `file` → 原生 `<video controls preload="metadata" playsInline>`，`startSec` 在 `loadedmetadata` 时跳；
   - `hls` → 原生 `<video>` + "Safari 原生可播、Chrome/Firefox 建议改 mp4"提示；
   - `bilibili` / `youtube` → **点击后才挂 iframe**，另给"原站打开"；
   - `page` → 跳转卡，不内嵌；
   - `invalid` → 显示可读 `reason` 的提示卡，不渲染黑框。
4. 「去练本节」：读取 `platform.settings.getPractice(bankId)`，只把 `topicIds` 改成 `[module.topicId]` 并把 `onlyUnseen` 置 false，其余字段不动，然后跳刷题页。
5. 接 `BanksPage` 讲义区（替换 `<details>` 列表），保持原有筛选/预览功能不变。
6. 写组件级测试：切换篇、目录锚点、非法地址提示、点击前无 iframe、去练本节只改 `topicIds`。
7. 样式落地：目录/正文/视频卡的桌面与移动端布局，焦点可见沿用既有 `:focus-visible` 规则。
8. 断网手测（B-4）与网络面板实测（B-3），截图/记录写进 `w3-ui-smoke.md`。

## 8. 本窗口特有风险

| 风险 | 缓解 |
| --- | --- |
| 站外 iframe 一进页面就发请求，违反离线可用 | 点击后才加载 + B-3 网络面板证据 |
| 视频 URL 绕过清洗造成注入 | 只信 W1 解析结果，UI 不拼裸 `src`；`invalid` 用纯文本卡 |
| 讲义体积拖慢首屏 | 集成时测 bundle 增量，超阈值改按需加载（与 W2/INT 协同） |
| 阅读进度被写进 Attempt/Progress | A-7 快照比对；明确"阅读位置 = 组件状态" |
| `RichText` 之外的第二套 HTML 注入口 | B-7 扩展点扫描兜底 |
