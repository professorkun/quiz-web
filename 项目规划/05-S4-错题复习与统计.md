## 1. 阶段目标

**目标陈述**：把"答过的题"变成"可追溯、可调度、可退出"的学习状态。核心是两件事：**答题事件不可变**（历史永不被覆盖），**掌握状态可重算**（统计与掌握度都只是事件的投影）。

**可衡量目标**

| 编号 | 指标 | 目标值 | 验证方式 |
| --- | --- | --- | --- |
| G4-1 | 事件不可变 | 重复作答产生新 `Attempt`，旧记录 0 覆盖 | 数据比对 |
| G4-2 | 复习规则可执行 | 1/3/7 天推进正确，连续 3 次独立答对转已掌握 | 时间旅行单测 |
| G4-3 | 错因可标记 | 5 类错因可选，可修改 | 手测 |
| G4-4 | 统计可重算 | 清空派生状态后由 Attempt 重算，结果一致 | 重算对账 |
| G4-5 | 首次正确率独立 | 重做不影响首次正确率 | 用例对照 |
| G4-6 | 收藏独立 | 答对/掌握/移出错题均不删除收藏 | 用例 |

---

## 2. 范围边界

**本阶段做**

- `Attempt`（不可变答题事件）写入与查询
- `QuestionProgress` 派生状态：`new / learning / reviewing / mastered`
- 错题状态机：进入、错误计数、连续答对、复习间隔、掌握退出
- 错因标记（知识漏洞 / 方法错误 / 审题不清 / 计算与输入失误 / 时间不足）
- 收藏（与错题分离）
- 到期复习列表与复习练习模式
- 统计：首次正确率、重复练习正确率、知识点覆盖率、掌握度、待复习量、学习时长
- 区分练习 / 复习 / 模考（模考数据在 S5 接入，此处先预留 `mode`）

**本阶段不做**

- 不做 FSRS / `ts-fsrs`（方案明确：先用透明规则，积累真实数据后再评估）
- 不做弱项推荐与自适应算法（S7）
- 不做模考（S5）
- 不做云同步（S6）
- 不做学习计划与每日目标（S7）

## 4. 任务分解

| ID | 任务 | 关键动作 | 产出 | 完成判据 | 量 |
| --- | --- | --- | --- | --- | --- |
| T4-1 | Attempt 写入管线 | 每次作答生成唯一 `Attempt`（含 `sessionId`、`mode`、`durationMs`、`isFirstAttempt`） | `core/stats` 或 `core/practice` 写入器 | 重复作答产生两条记录，旧记录不变 | M |
| T4-2 | 状态机 | 答错 → `learning`；复习答对 → `reviewing` + 排下次；连续 3 次独立答对 → `mastered`；任一答错 → 重置 | `core/review` 状态机 | 状态迁移表用例全过 | M |
| T4-3 | 复习调度 | 1 天 → 3 天 → 7 天；到期判定；`nextReviewAt` 计算 | `core/review` 调度器 | 时间推进单测（可注入时钟）通过 | M |
| T4-4 | 错因与备注 | 5 类错因标记，可修改；备注可选 | 复习页交互 + 存储 | 错因持久化，可改可清 | S |
| T4-5 | 收藏 | 独立于错题，任何状态变化不删除 | 收藏模块 | 答对并掌握后收藏仍在 | S |
| T4-6 | 复习页 | 到期复习、错题、收藏、掌握状态四个视图 | 复习功能模块 | 各视图数据与状态机一致 | M |
| T4-7 | 统计 | 首次正确率、重复正确率、覆盖率、掌握度、待复习量、学习时长 | `core/stats` + 统计组件 | 数值可由事件重算，且与界面一致 | M |
| T4-8 | 重算与对账 | 提供"由 Attempt 重算 Progress/统计"的能力 | 重算命令/函数 | 重算前后结果一致 | S |

**复习规则（方案 §6.4，逐条落地，不做"差不多"）**

| 事件 | 状态变化 |
| --- | --- |
| 答错 | 进入错题，错误次数 +1，连续答对清零，立即可重做 |
| 重做答对 | 进入复习计划，**不**立即永久移出错题 |
| 复习间隔 | 默认 1 天 → 3 天 → 7 天 |
| 连续 3 次独立复习答对 | 标记已掌握，可从默认错题列表隐藏 |
| 任一复习答错 | 重置连续答对，重新进入待复习 |
| 错因 | 知识漏洞 / 方法错误 / 审题不清 / 计算与输入失误 / 时间不足 |
| 收藏 | 独立保存，不因答对或掌握而消失 |
| 历史 | 所有答题事件保留；移出错题 ≠ 删除历史 |

## 6. 验收标准

### A. 事件与状态

- [ ] 每次作答生成新 `Attempt`，含 `bankId`、`questionId`、`questionRevision`、`sessionId`、`mode`、`durationMs`、`isFirstAttempt`
- [ ] 同一题重复作答不覆盖任何历史 `Attempt`
- [ ] `QuestionProgress` 由事件推导，不手工直接写"做对过"
- [ ] 状态迁移覆盖：`new → learning → reviewing → mastered`，以及任一环节答错后的回退
- [ ] 连续 3 次**独立复习**答对才转 `mastered`；同一会话内连点不计数

### B. 复习调度

- [ ] 复习间隔按 1 / 3 / 7 天推进，`nextReviewAt` 计算正确（含时钟注入测试）
- [ ] 到期列表只含 `nextReviewAt <= now` 的题，且不含 `mastered`
- [ ] 复习中答错，该题立即重新进入待复习，连续答对归零

### C. 错因与收藏

- [ ] 5 类错因可选、可改、可清空
- [ ] 收藏与错题互不影响：答对并掌握后收藏仍在
- [ ] 移出错题后历史事件仍可查

### D. 统计

- [ ] 首次正确率只统计 `isFirstAttempt` 的记录，重做不抬高
- [ ] 重复练习正确率单独统计
- [ ] 知识点覆盖率、掌握度、待复习量、学习时长均有明确计算口径
- [ ] 清空派生数据后由 `Attempt` 重算，结果与清空前一致
- [ ] 练习 / 复习 / 模考三类数据可分别统计（`mode` 生效）

### E. 关键场景（Given / When / Then）

1. **答错不丢轨迹**
   Given 某题首次答错、随后连续答对 3 次（分属 3 次不同复习），When 该题转为已掌握，Then 首次正确率仍记为"错"，历史 4 条 `Attempt` 全部保留，错题列表默认隐藏但历史可查。
2. **复习推进**
   Given 某题在 T 日答错，When 在 T+1 日复习答对，Then 该题进入 `reviewing`，`nextReviewAt` 为 T+4 日（3 天后），再次答对后为 T+11 日（7 天后）。
3. **答错重置**
   Given 某题已连续 2 次复习答对、等待第 3 次，When 第 3 次答错，Then 连续答对归零，状态回到待复习，`nextReviewAt` 重置为次日。
4. **统计可重算**
   Given 已有 200 条 `Attempt` 与派生统计，When 删除所有 `QuestionProgress` 与统计缓存并重算，Then 全部指标与重算前一致。
5. **收藏独立**
   Given 某题被收藏且是错题，When 该题经复习转为已掌握并移出错题列表，Then 收藏列表仍包含该题。
6. **未登录不丢**
   Given 游客答错 5 题，When 关闭浏览器次日重新打开，Then 这 5 题仍在待复习中，间隔按首次答错时间计算。

### F. 不可接受的情形

- 用"是否做对过"布尔值代替状态机
- 一次答对就永久移出错题、历史轨迹不可查
- 首次正确率把重做也算进去
- 统计直接累加计数器而无法重算
- 收藏被"错题掌握"顺带清掉
- 直接上 FSRS 或复杂自适应算法

## 8. 阶段特有风险与应对

| 风险 | 触发信号 | 应对 |
| --- | --- | --- |
| 复习规则越调越玄 | 出现"再考虑一下权重"的讨论 | 锁定透明规则，权重类设计留到 S7 用真实数据评估 |
| 状态与事件双写不一致 | 界面显示与重算结果不同 | 以事件为唯一真源，状态只做缓存并定期重算校验 |
| "独立复习"定义含糊 | 同会话连点被算 3 次答对 | ADR 明确：不同复习会话 + 距上次超过间隔才算独立 |
| 时区/跨日判断出错 | 跨零点后到期列表异常 | 时钟注入 + 自然日口径统一，测试覆盖跨日 |
| 统计口径膨胀 | 指标越加越多 | 只做方案 §6.2 列出的 5 项，新指标进 S7 |

---

## 9. 回退方案

1. 状态回退：删除派生状态 → 由 `Attempt` 重算，等价于"回到任何时候"。
2. 规则回退：复习间隔配置化，回退只需改配置，不改数据。
3. 版本回退：回到 `s3-local-mvp`，错题仍可见（只是没有调度），数据不损坏。
